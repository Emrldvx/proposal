The ledger · PRD §8

Every Naira accounted for, every request counted once

The ledger is what lets the app pass security review. Balances are never edited directly; they are the sum of balanced entries.

A ₦50,000 withdrawal

Each movement writes balanced entries. The 2% fee is its own line, as your PRD requires, so fee revenue reports straight from the ledger.

AccountDebitCredit
Customer wallet₦50,000—
Bank payout (in transit)—₦49,000
Fee revenue (2%)—₦1,000

Example figures for illustration. Minimum and maximum fee caps apply when set.

No double payouts

Mobile networks drop and users tap twice. The backend makes sure that never moves money twice.

  1. The app sends each money request with a unique idempotency key.
  2. The backend records the key before calling any partner.
  3. A repeated request with the same key returns the first result instead of paying again.
  4. Partner webhooks are matched to the original request and reconciled daily.
  5. Mismatches raise an alert and appear in the reconciliation report for operations.

FAQ

Questions you might be asking

Do we need our SEC licence before you start?

No. Setup, the ledger, wallet and KYC can start in week 9. The crypto liquidity integration waits for the partner you choose with your licensing route.

Partner-held custody or our own keys: what changes?

Partner-held balances are faster and cheaper to build. Holding your own keys needs a hardware security module, key procedures and on-chain monitoring, which moves the price towards the top of the range.

How do you stop double withdrawals?

Every money request carries a unique key. If the same request arrives twice, the backend returns the first result instead of paying again, and daily reconciliation flags any mismatch.

Can we change the 2% withdrawal fee later?

Yes. The fee, its minimum and maximum caps, tier limits and rates are all set from the admin dashboard, with a history of every change. No code changes needed.

Will it cope as we grow?

It is designed to grow from thousands to hundreds of thousands of users, with a 99.9% uptime target, daily backups and monitoring alerts.

Is a penetration test included?

It is optional, at $3,000 – $8,000 through an independent firm. We build to pass it and fix any findings in our code before launch.

What will hosting cost each month?

Usually $300 – $1,500 per month, paid directly to the provider. It starts low and grows with your number of users.
